# PumBot — Arbeitsanweisung

Discord-Bot in Python (`discord.py`). Aufbau, Funktionsumfang und Betrieb stehen in
[README.md](README.md); hier stehen nur die Regeln, die beim Arbeiten am Code gelten.

## Rechtliches

Was **personenbezogene Daten** erhebt, speichert, länger aufbewahrt oder an einen Dritten
weitergibt, braucht einen Eintrag in `c:\Development\PumpeBot_Next\docs\rechtliches\` —
zusammen mit der Änderung, nicht später. Betrifft hier vor allem Nachrichtenprotokolle,
Tickets samt Transkripten, Verwarnungen, verknüpfte Konten und jeden Aufruf eines fremden
Dienstes mit Nutzerinhalten.

Der Ordner liegt im Web-Repository, weil dort die Datenschutzerklärung entsteht — Bot und
Plugins haben keine eigene. Wann ein Eintrag fällig ist und wie er aussieht, steht in
dessen `README.md`.

## Sprache

Befehlsnamen und Bezeichner im Code auf Englisch, alles was ein Nutzer auf Discord sieht
auf Deutsch.
